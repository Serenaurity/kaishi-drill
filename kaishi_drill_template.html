No JP keyboard needed: the reading drill accepts romaji (typed on a normal keyboard, e.g. nihongo) as well as kana, checked against the deck's own reading field — including words with more than one valid reading, like 何 → なに / なん.

How grading works: readings are matched exactly (romaji is converted from the deck's kana, not guessed). The translation drill uses a rough keyword-overlap heuristic, not real judgment — the actual app would replace this step with local-model grading for meaning, tolerant of paraphrase. Anki itself is never touched: this reads deck content only, nothing writes back.

Kana recap & activity graph: the kana mode drills the full hiragana/katakana chart (dakuten, handakuten, youon) independent of the deck, using the same romaji matching as the reading drill. The activity graph counts every checked answer across all three modes and is stored locally in this browser only — it won't follow you to another device and resets if site data is cleared.
